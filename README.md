# Customer Retail Machine Learning Project

## Project Objective
Compare multiple Machine Learning algorithms using a customer retail dataset.

## Algorithms Used
- Logistic Regression
- Decision Tree Classifier
- K-Nearest Neighbors (KNN)

## Features
- Quantity
- UnitPrice

## Target
- Country

## Evaluation Metrics
- Accuracy Score
- Confusion Matrix

## Visualizations
- Customer Distribution Graph
- Model Accuracy Comparison Graph

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn

## Results
The project compares three classification models and identifies the best-performing algorithm based on accuracy.
